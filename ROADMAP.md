# Roadmap

What is being worked on next. Not a commitment — a direction. Shipped work moves to [CHANGELOG.md](CHANGELOG.md).

## Upcoming

- **Profile presets** — `skilldrop install --profile <name>` installs a named bundle of packs, agents, and loops in one command; no per-skill selection needed for common setups
- **Full docs portal** — per-guide navigable pages with sidebar and deep links; currently all guides are GitHub markdown files without a searchable index
- **Integration guides** — per-tool how-to guides for Jira, GitHub Projects, Figma, and Linear covering how to feed their outputs into skilldrop skills
- **Credential brokering** — a guide and reference for skills that declare `env.required`; covers secret injection patterns for local, CI, and enterprise vault setups
- **Scenario walkthroughs** — guided sessions per role: solution architect, product manager, dev team, AI engineering (in progress)
