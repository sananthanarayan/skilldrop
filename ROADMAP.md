# Roadmap

What is being worked on next. Not a commitment — a direction. Shipped work moves to [CHANGELOG.md](CHANGELOG.md).

## Upcoming

- **Docs portal search** — client-side full-text search across all guide pages in the docs portal, so a visitor can find a guide without knowing its Diátaxis kind
- **Scenario walkthroughs** — end-to-end worked examples that span multiple loops and roles (e.g. "from stakeholder complaint to closed incident using discover → operate")
- **Skills for Claude API workflows** — a pack for teams building on the Anthropic API: prompt-caching advisor, token-budget estimator, eval harness generator, and tool-use schema writer
- **Contribution wizard** — a meta-skill that walks an author through creating a new skill: generates the manifest, SKILL.md, eval cases, and README entry from a plain-language description
