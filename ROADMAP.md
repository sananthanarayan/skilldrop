# Roadmap

What is being worked on next. Not a commitment — a direction. Shipped work moves to [CHANGELOG.md](CHANGELOG.md).

## Upcoming

- **Syntax highlighting in the docs portal** — Prism.js on code blocks in rendered guide pages so shell commands, JSON, and Python snippets are coloured correctly
- **MCP integration guide** — how to combine skilldrop skills with Claude Code MCP servers; which skills pair naturally with the Figma MCP, Linear MCP, and GitHub MCP
- **GitHub Actions skill runner** — a reusable workflow that lets CI pipelines invoke a skill directly (e.g. run `pre-merge-review` as a required check on every PR)
- **Skill evaluations dashboard** — a page in the docs portal that renders each skill's eval cases and their pass/fail shape, making quality visible to contributors
