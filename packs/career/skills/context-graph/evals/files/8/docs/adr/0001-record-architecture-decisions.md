# 1. Record architecture decisions

Date: 2024-01-10

## Status

Accepted

## Context

We need to record the architectural decisions made on this project.

## Decision

We will use Architecture Decision Records, as described by Michael Nygard, kept in `docs/adr/`.
Larger proposals that need discussion first go in `docs/rfcs/` and become an ADR once accepted.

## Consequences

See Michael Nygard's article for a detailed description of the process.
