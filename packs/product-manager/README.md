## Start here: Pressure-test a product idea before anyone builds it

Paste this into Claude Code:

```text
Write a PR/FAQ for a feature that lets customers pause their subscription for up to three months instead of cancelling.
```

- **How to tell it worked:** prfaq returns a launch press release, a customer FAQ and an internal FAQ that names the hard questions.
- **If nothing happens:** If prfaq does not activate, ask for it by name ("use prfaq") and check that its folder exists in your skills folder (`~/.claude/skills/` by default).
