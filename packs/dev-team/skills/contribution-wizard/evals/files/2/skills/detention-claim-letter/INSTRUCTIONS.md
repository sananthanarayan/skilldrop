# detention-claim-letter

## Purpose

When a driver is held at a facility past the agreed free time, Larkfield claims detention from the party that caused the delay. This skill drafts that letter with the arithmetic shown so the recipient can check it.

## Steps

1. Work out time on site: departure minus arrival, in hours and minutes.
2. Subtract the free time. If the result is zero or less, say that no detention is owed and stop.
3. Bill the remainder in the increments the terms state. If the terms do not state an increment, bill in 15-minute increments rounded down.
4. Apply the cap if the terms state one.
5. Write the letter: load number, facility, the timestamps, the calculation line by line, the amount claimed, and a reply-by date 14 days from the letter date.
6. End the output with one line listing what evidence to attach (the signed bill of lading with in and out times).

## Never

- Never claim an amount without showing the timestamps it came from.
- Never round time on site up.
- Never state that payment is overdue; this is a first claim.
