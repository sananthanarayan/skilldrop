# flag-overdue-holds

You are given the hold-shelf report: one line per item with request number, title,
patron name, card number and the date the item was shelved.

1. List every item shelved more than 7 days before the report date, oldest first.
2. For each, give the request number, the title and the patron's name.
3. Never repeat a library card number. Refer to the patron by name.

If nothing is over 7 days, say so.
