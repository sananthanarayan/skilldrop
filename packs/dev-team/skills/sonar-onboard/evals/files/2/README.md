# Wayline

Timetable and departure-board service for Harrow Valley Transit (invented example project).

- `src/wayline/` — Python service (timetable merge, departure predictions).
- `src/wayline/_generated/` — generated by protoc from the stop-feed schema. Do not edit by hand.
- `src/wayline/vendor/gtfs_lite/` — a vendored copy of a third-party feed parser, pinned. Not our code.
- `tests/` — pytest suite for the Python service.
- `web/` — TypeScript departure-board frontend; Jest tests sit next to the code as `*.test.ts`.

CI runs on our GitLab instance (see `.gitlab-ci.yml`).
