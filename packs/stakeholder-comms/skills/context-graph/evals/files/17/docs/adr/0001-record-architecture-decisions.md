# ADR-0001: Record architecture decisions

Status: Accepted
Date: 2024-02-05
Deciders: Mara Lindqvist

We keep ADRs in `docs/adr/` and cross-service RFCs in `docs/rfcs/`. Each record has a
Status line. When a record is replaced, both records say so: the old one becomes
"Superseded by X" and the new one says "Supersedes Y".
