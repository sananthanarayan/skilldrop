# Voltbay voice notes

- Plain and calm. People reading this may be stressed, late or cold.
- Never tell users to contact support for things they can fix themselves.
- Never show raw error codes as the whole message. A code can appear small at the end so a caller can quote it.
- The price per kWh is set by each site owner and can change daily. The screen gets it from the network at runtime; the copy must not hardcode a figure.
- A support phone number will be printed on a sticker on each unit. We don't have the number per site yet.
- Product team keeps calling the unit different things: "station", "charge point", "charger", "pump". We want one name, used everywhere on screen.
