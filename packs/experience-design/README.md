# Experience design

The experience around a product: the structure people navigate, the content and interface words they read, the components they use, and the service behind it all.

`/plugin install experience-design@skilldrop` · generated from [`main`](https://github.com/sananthanarayan/skilldrop) — do not edit.

## Start here: Restructure a menu users get lost in, and get the test that proves the new one works

Paste this into Claude Code:

```text
Our help centre menu has grown to 15 items and customers can't find refunds or delivery tracking. Current menu: Getting Started, Account, Orders, Shipping, Delivery, Returns, Refunds, Payments, Gift Cards, Promotions, Membership, Privacy, Terms, Contact Us, Community. Design the information architecture and the tree test to validate it.
```

- **Before you start:** A current menu, page list or feature list for the product, and who uses it
- **How to tell it worked:** information-architecture returns an inventory with a keep/merge/cut status for every item, a sitemap tree and a Mermaid diagram that match, a label rationale table, findability risks for refunds and tracking, and tree-test tasks that don't use the menu's words.
- **If nothing happens:** If you get a journey map instead, ask for it by name ("use information-architecture"). If labels look invented, give it your search terms or support ticket themes and ask it to tag every label's evidence.
