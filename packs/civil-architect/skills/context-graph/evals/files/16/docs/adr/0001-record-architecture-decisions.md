# ADR-0001: Record architecture decisions

Status: Accepted
Date: 2025-01-14
Deciders: Priya Natarajan

## Decision

We record significant decisions as numbered ADRs in `docs/adr/`. An ADR that is
replaced or changed by a later one says so in its Status line ("Superseded by
ADR-NNNN" or "Amended by ADR-NNNN"), and the later ADR says what it supersedes
or amends.
