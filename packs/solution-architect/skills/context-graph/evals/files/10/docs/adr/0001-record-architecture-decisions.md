# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2022-11-02

## Decision

We record significant architecture decisions as numbered markdown files in `docs/adr/`.
When a decision replaces an earlier one, the new record says `Supersedes: ADR-NNNN` and the
old record's status is changed to `Superseded by ADR-MMMM`.
