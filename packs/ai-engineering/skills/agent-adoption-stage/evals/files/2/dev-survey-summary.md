# Developer survey on AI coding agents - summary

Run: 4-15 August 2026, optional, anonymous. 29 responses.

- 93% say they use AI coding agents "every working day".
- 61% agree with "agents now write most of my code".
- 72% say code review is the slowest part of getting agent work merged.
- Top request: "let me run more than one agent at a time without my laptop grinding to a halt".
- 4 respondents said they had stopped using agents because their PRs "sit in the queue for days".
