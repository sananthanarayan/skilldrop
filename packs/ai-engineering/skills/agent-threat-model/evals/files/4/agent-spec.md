# Tenant-support agent - specification

Purpose: answer tenants' emails about rent, repairs and deposits, so the support team can focus
on complex cases.

Capabilities:

1. Reads the tenant-support inbox. Anyone can email this address.
2. Looks up the tenant's record in LetHub (our CRM): name, address, phone, rent ledger, bank
   details held for deposit refunds, and scanned ID documents (passport or driving licence).
3. Sends email replies.
4. Creates repair tickets in the contractor portal. Contractors see the ticket text.
5. Opens web links included in tenants' emails, so it can look at photos or documents tenants
   share by link.
6. Appends a note to the shared "Tenant notes" document, which all 40 staff can read.

Launch: Monday, all tenancies (about 2,300).
