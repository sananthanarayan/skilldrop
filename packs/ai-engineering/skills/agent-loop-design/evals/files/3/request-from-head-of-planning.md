# Request: AI agent for householder applications

We have a backlog of 340 householder applications (rear extensions, loft conversions, porches).
I want an agent that:

1. Checks each application against the Householder Design Guide.
2. Where something is missing, emails the applicant asking for it, and re-checks the application
   when it arrives.
3. Auto-approves the straightforward ones, so officers only see the hard cases.

Target: backlog cleared by the end of January 2027.
