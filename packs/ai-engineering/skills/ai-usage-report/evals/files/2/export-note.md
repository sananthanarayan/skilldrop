# About this export

- Source: Draftwell admin console, "Activity events" export, covering 1-28 September 2026.
- Events: `generate` (Draftwell produced a draft), `insert` (the draft was inserted into a working
  document), `discard` (the user deleted the draft).
- Message from Draftwell support: events for 15-21 September were lost in a logging outage on
  their side and cannot be recovered.
- `published-assets.csv` is our own list of client work published between 1 September and 2 October. The last column
  lists any Draftwell drafts used in that piece (blank = no Draftwell draft used).
