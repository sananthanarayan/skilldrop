**General marking guidance**
- Award marks for correct chemistry even if expressed differently from the wording below.
- Calculations: award full marks for a correct final answer with no working unless otherwise stated.
- Error carried forward (ecf): if an earlier value is wrong but used correctly later, award the later marks.
- Units are required where stated in the answer column; deduct 1 mark once per question for a missing unit.
- Significant figures: penalise only where the question asks for a stated number of significant figures.
- Do not credit answers that contradict a correct statement elsewhere in the same part.
- Use (1) to show each creditable point; (up to n) where marks are pooled.
- Annotate scripts with ticks in the margin; record the part total in the right-hand box.
- Moderation sample: every fifth script plus the highest and lowest totals.
