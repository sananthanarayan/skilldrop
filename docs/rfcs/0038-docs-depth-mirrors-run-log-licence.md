# RFC-0038: Generated pack guides, internal mirrors, a loop run log, and a dual licence

## Problem / use case

The 2026-10-01 comparison with agent-ready-repo listed four longer-term gaps:
- **Docs depth:** a reader can't find a how-to and a reference page for each pack.
- **Internal mirrors:** an enterprise can't host a vetted copy of the catalogue.
- **Gate data:** nobody can see which loop gates actually fail.
- **Licensing:** legal teams often ask for Apache-2.0's patent grant, and the repo is MIT only.

## Fit check

These are structural changes. They touch:
- **One producer per artifact (RFC-0028).** The pack guides are generated by
  `build_pack_guides.py` from `pack.json`, manifests, SKILL.md and `loop.json`, and
  `validate.py` fails on drift, so they can't disagree with the catalogue.
- **Skills never invoke skills.** The run log is a line every LOOP.md carries. It appends to a
  local file only when `SKILLDROP_LOOP_LOG` is set, and calls nothing.
- **Zero dependencies, offline.** `package`, `init-catalogue` and `loop-stats` are stdlib Node.
  Nothing leaves the machine.

## Proposal

- **Pack guides:** `guides/how-to/packs/use-the-<pack>-pack.md` and
  `guides/reference/packs/pack-<pack>.md`, generated, plus an index table in
  `guides/README.md` between markers. The docs portal groups them under "Per pack".
- **Mirrors:** `skilldrop package <dir> [--pack] [--skills] [--agents]` writes a standalone
  catalogue and a `MIRROR.json` that records the source and a SHA-256 per file.
  `skilldrop init-catalogue <dir>` starts a private one with a validate-and-scan workflow.
- **Run log:** every LOOP.md has a `## Run log (opt-in)` section (enforced by `validate.py`).
  Each line is `{ts, loop, stage, gate, verdict, round}`. `skilldrop loop-stats` summarises it
  using the `terminals.json` verdict classes.
- **Licence:** `LICENSE` states MIT OR Apache-2.0. `LICENSE-MIT` and `LICENSE-APACHE` hold
  the texts. Every commit before this change is the maintainer's, apart from two Dependabot
  version bumps, so no other contributor's consent was needed.

## Alternatives considered

- **Hand-written pack guides.** Rejected: 2 × 17 pages that silently drift from the skills
  they describe.
- **Telemetry sent to a server.** Rejected: skilldrop stays offline. A team that wants
  aggregates can combine `loop-stats --json` itself.
- **A tarball for `package`.** Rejected: a folder can be reviewed, diffed, and pushed to git as is.

## Decision

Accepted by the maintainer on 2026-10-01 ("do … larger, longer-term work"). Ships in 0.15.0.
